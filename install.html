안드로이드 갤럭시 등

  1. 위 주소를 크롬 또는 삼성 인터넷으로 엽니다.
  2. 로그인하면 화면 위에 “📲 앱 설치” 버튼이 떠요. 탭 한 번이면 설치 창이 나옵니다.
  3. [설치]를 누르면 끝! 홈 화면에 아이콘이 생깁니다.
버튼이 안 보이면: 브라우저 ⋮ 메뉴 → 앱 설치 또는 홈 화면에 추가

아이폰 Safari

  1. 위 주소를 Safari로 엽니다. (크롬 말고 Safari)
  2. 화면 아래 가운데 공유 버튼 ⬆️ 을 누릅니다.
  3. 메뉴를 내려 “홈 화면에 추가”를 선택 → [추가].
아이폰은 애플 정책상 자동 설치가 없어, 이 2~3단계가 유일한 방법이에요.
